# 01. Product

## 목표

**팀 업무 시각화** — "지금 누가 뭐해?"가 사라지게 만든다.

팀원들이 각자 무엇을 하고 있는지, 무엇이 지연되고 있는지를 별도로 물어보지 않아도 한눈에 파악할 수 있는 화면을 제공한다.

## 페르소나

- **10명 규모 스타트업 팀 리더** (30~40대)
- 여러 팀원의 업무 현황을 매일 확인해야 하지만, 슬랙/구두 보고로는 파악이 늦고 누락이 생김
- 복잡한 기능보다 "빠르게 보고 빠르게 파악"할 수 있는 도구를 원함

## MVP 범위

### CRUD 4종 (화면에서 모두 동작)

- **추가**: 새 업무 생성
- **목록**: 업무 목록 조회
- **수정**: 업무 내용/상태/마감 수정
- **삭제**: 업무 삭제

### 업무 속성

- **상태 분류**: 업무 상태 구분 (예: 할 일 / 진행 중 / 완료)
- **마감 시각(`due_at`)**: 날짜뿐 아니라 **시간까지** 지정 및 표시
  - 표시 형식 예: `2026-05-12 18:00`

### UI/UX

- **라이트/다크 테마 토글**: 선택값을 `localStorage`에 저장하여 새로고침 후에도 유지
- **모바일 반응형**: 최소 360px 너비에서 레이아웃이 깨지지 않음

## UI 톤

**Mac OS 스타일**

- 둥근 모서리 (rounded corners)
- 부드러운 그림자 (soft shadow)
- 반투명 카드 (translucent card / blur 배경)
- 시스템 폰트 (system font stack, 별도 웹폰트 미사용)

## 확장 범위 (MVP 이후, 별도 협의 후 진행)

- JWT 로그인
- 팀 기능 (다중 사용자/팀 단위 관리)
- Kanban 보드
- 채팅
- CI/CD 파이프라인

## 범위 외 (Out of Scope)

- 외부 결제
- 네이티브 앱
- WebRTC
- 외부 캘린더 연동
- 파일 업로드
- **WebSocket** — MVP는 폴링(polling) 방식 사용. WebSocket은 확장 단계로 보류

## 성공 기준

- [ ] 새로고침 후에도 테마/상태 유지
- [ ] 360px 너비에서 레이아웃이 깨지지 않음
- [ ] API 응답 200ms 이내
- [ ] CRUD 4종이 화면에서 모두 정상 동작
- [ ] 테마 토글이 정상 작동
