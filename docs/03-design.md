# 03. Design

## 아키텍처 결정 기록 (8개)

각 결정은 **선택 / 대안 / 근거 / 트레이드오프**로 정리한다.

### 1. 백엔드

| 항목 | 내용 |
|---|---|
| 선택 | FastAPI |
| 대안 | Django, Express |
| 근거 | Pydantic 기반의 자동 검증/직렬화로 `02-specs.md`의 검증 규칙(title/status/due_at 형식)을 코드로 명확히 표현 가능. 비동기 지원, 자동 API 문서(OpenAPI) 제공 |
| 트레이드오프 | Django 대비 배터리 미포함(admin, ORM 등 직접 구성 필요). Express 대비 Python 생태계에 종속 |

### 2. 프론트엔드

| 항목 | 내용 |
|---|---|
| 선택 | Vanilla JS + Tailwind CDN |
| 대안 | React, Vue |
| 근거 | MVP 범위(CRUD 4종 + 테마 토글)는 상태 관리 복잡도가 낮아 프레임워크 없이도 충분. 빌드 단계 없이 즉시 실행/배포 가능 |
| 트레이드오프 | 기능이 커지면 DOM 직접 조작의 유지보수 비용 증가. 컴포넌트 재사용성 낮음 |

### 3. 데이터베이스

| 항목 | 내용 |
|---|---|
| 선택 | SQLite → PostgreSQL + SQLAlchemy |
| 대안 | (없음 — 단계적 전환 전략) |
| 근거 | 로컬 개발/MVP 단계는 SQLite로 설정 비용 없이 시작. SQLAlchemy를 ORM으로 두어 PostgreSQL 전환 시 쿼리 코드 변경 최소화 |
| 트레이드오프 | SQLite는 동시 쓰기 성능이 낮아 다중 사용자 확장 시 PostgreSQL 마이그레이션 필수. 전환 시점에 스키마/설정 작업 필요 |

### 4. CSS

| 항목 | 내용 |
|---|---|
| 선택 | Tailwind만 사용 |
| 대안 | styled-components (금지) |
| 근거 | 유틸리티 클래스만으로 Mac OS 톤(rounded, shadow, blur)을 일관되게 적용 가능. 빌드 의존성 최소화 |
| 트레이드오프 | 클래스명이 길어져 마크업 가독성 저하 가능. 복잡한 애니메이션/테마 로직은 표현이 번거로움 |

### 5. 실시간성

| 항목 | 내용 |
|---|---|
| 선택 | MVP는 폴링 (3초 간격) |
| 대안 | WebSocket (확장 단계로 보류) |
| 근거 | 팀 리더 1인 대시보드 시나리오에서는 실시간 push 없이도 3초 지연이 사용성에 문제 없음. 서버/인프라 복잡도 최소화 |
| 트레이드오프 | 불필요한 요청으로 서버 부하 발생 가능. 다중 사용자 동시 편집 시 지연 체감 증가 |

### 6. 상태 관리

| 항목 | 내용 |
|---|---|
| 선택 | 모듈 변수 + DOM 직접 갱신 |
| 대안 | (프레임워크 상태 관리 라이브러리 — 해당 없음, Vanilla JS 채택에 따름) |
| 근거 | Task 목록이라는 단일 데이터 소스만 다루므로 별도 상태 관리 라이브러리 없이 모듈 스코프 변수로 충분 |
| 트레이드오프 | 상태-화면 동기화를 수동으로 관리해야 하므로 기능 추가 시 갱신 누락 위험 존재 |

### 7. 디자인 시스템

| 항목 | 내용 |
|---|---|
| 선택 | Mac OS UI 톤 |
| 대안 | Material, Ant |
| 근거 | `01-product.md`에 정의된 제품 톤(둥근 모서리, 부드러운 그림자, 반투명 카드, 시스템 폰트) 요구를 직접 만족 |
| 트레이드오프 | 기성 컴포넌트 라이브러리가 없어 컴포넌트를 직접 정의해야 함 |

**디자인 토큰**

| 토큰 | 값 |
|---|---|
| 모서리 | `rounded-xl` |
| 그림자 | `shadow-lg` |
| 카드 배경 | `backdrop-blur` |
| 폰트 | 시스템 폰트 스택 (webfont 미사용) |
| 터치 타깃 | 최소 `44px` |

### 8. 테마

| 항목 | 내용 |
|---|---|
| 선택 | 라이트/다크 토글 |
| 대안 | (단일 테마 — 채택 안 함) |
| 근거 | 다크 모드는 Tailwind `dark:` 변형(variant)으로 스타일을 분기하고, 선택값은 `localStorage('theme')`에 저장하여 새로고침 후에도 유지. 초기값은 `prefers-color-scheme` 미디어 쿼리를 따름 |
| 트레이드오프 | 모든 컴포넌트에 `dark:` 변형을 이중으로 정의해야 하는 작업 비용 발생 |

## 의존성 추가 정책

새 라이브러리/패키지를 추가하려면 반드시 이 문서(`03-design.md`)에 **선택 / 대안 / 근거 / 트레이드오프**를 결정 기록 형식으로 추가한 뒤에만 도입할 수 있다. 사유를 적기 전에는 어떤 의존성도 추가하지 않는다.
